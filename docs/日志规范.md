# 日志规范

> 适用项目：AI 求职信息智能筛选助手
> 适用范围：全部业务模块（当前已实现：模块一 群监听配置、模块二 多模态消息解析、模块三 用户简历&求职意向配置、模块四 AI 岗位结构化抽取、模块五 岗位匹配打分、模块六 本地数据归档与日报、业务插件层 残缺补全/公司风评检索）
> 文档索引：返回 [README.md](../README.md) 文档索引 ｜ 配套规范：[错误码体系.md](错误码体系.md)、[异常处理指南.md](异常处理指南.md)

## 一、日志级别规范

| 级别 | 使用场景 | 示例 |
| --- | --- | --- |
| ERROR | 异常、连接失败、不可恢复错误 | NapCat 连接失败、配置加载失败 |
| WARN | 可恢复的异常情况 | 收到非 JSON 报文、非监听群消息被丢弃 |
| INFO | 关键流程节点 | 监听启动/停止、连接成功、消息命中白名单 |
| DEBUG | 调试期明细（默认关闭） | 消息字段级细节 |

## 二、打印规范

1. **必须携带模块标识**：通过 logger 命名空间区分，如 `job_assistant.listener.napcat_client`、`main`
2. **必须携带业务标识**：群号（group_id）、消息 ID（message_id）等关键业务键
3. **禁止打印敏感信息**：手机号、密码、QQ 号完整值（日志中群号除外，群号属配置项）、消息全文、简历/求职意向全文
   - 消息内容一律以**摘要**形式记录：`text_len`、`images`、`urls` 数量，不打印原文；简历/意向仅记录 `resume_len`、`intention_len`
4. **格式统一**：`%(asctime)s [%(levelname)s] %(name)s: %(message)s`（main.py 已配置）

## 三、模块一日志点清单（当前实现）

| 日志点 | 级别 | 内容 |
| --- | --- | --- |
| 配置加载完成 | INFO | ws_url、监听群数量、重连间隔 |
| 监听已启动 / 已停止 | INFO | ws_url / 运行时长、收到事件数、命中数 |
| 已连接 NapCat | INFO | ws_url |
| NapCat 连接失败/断开 | ERROR | 错误原因、重连间隔 |
| 非监听群消息丢弃 | WARN | group_id |
| 命中监听群消息 | INFO | group_id、message_id、text_len、images、urls |
| 非 JSON 报文忽略 | WARN | - |
| 监听线程异常退出 | ERROR | 完整堆栈（logger.exception） |

## 四、模块二日志点清单（当前实现）

| 日志点 | 级别 | 内容 |
| --- | --- | --- |
| 多模态处理完成 | INFO | group_id、message_id、merged_len、ocr 数、web 数、errors 数 |
| 消息处理存在失败分支 | WARN | group_id、message_id、失败分支数 |
| 图片下载完成 | INFO | url、文件名、字节数 |
| OCR 完成 / 无有效文本 | INFO | url、文本长度 / url |
| OCR 识别失败 | ERROR | url、错误信息（含错误码；超时含 `ocr_timeout`） |
| 网页抓取完成 / 无有效正文 | INFO | url、正文长度 / url |
| 网页策略跳过（需登录 / JS 渲染） | INFO | url、跳过原因 |
| 网页抓取失败 | ERROR | url、错误信息（含错误码） |
| 数据归档（raw_msg/ocr/web） | INFO | 文件名、字节数 |
| HTML 解析异常 | WARN | - |

## 五、模块三日志点清单（当前实现）

| 日志点 | 级别 | 内容 |
| --- | --- | --- |
| 用户画像加载完成 | INFO | resume_len、intention_len（**不打印内容**，敏感信息保护） |
| user_resume 为空 | WARN | -（后续岗位打分缺少简历参考） |
| user_intention 为空 | WARN | -（后续岗位打分缺少求职意向参考） |
| 简历/意向类型非法 | 入口统一处理 | 抛 ConfigError（CFG.LOAD.001），提示修正配置后重启 |

## 六、模块四日志点清单（当前实现）

| 日志点 | 级别 | 内容 |
| --- | --- | --- |
| LLM 调用完成 | INFO | endpoint、返回文本长度（**不打印 api_key、不打印消息/岗位全文**） |
| 消息分类完成 | INFO | category 枚举值 |
| 消息非招聘相关，跳过抽取 | INFO | category（闲聊广告/诈骗/其他不进入抽取） |
| 结构化抽取完成 | INFO | company、job、输入文本长度（岗位仅摘要，不打印全文） |
| 消息 AI 解析失败 | WARN | group_id、message_id、错误信息（含错误码 PAR.LLM.001/002） |
| 抽取响应格式非法，重试 | WARN | 第几次重试、错误信息 |
| 抽取重试后仍失败 | WARN | 错误信息（含错误码） |
| 分类响应无法解析为 JSON | WARN | 响应长度（兜底为 OTHER，不抛异常） |
| AI 解析完成 | INFO | group_id、message_id、category、岗位摘要（公司/岗位/类别）或非招聘类别 |

## 七、模块五日志点清单（当前实现）

| 日志点 | 级别 | 内容 |
| --- | --- | --- |
| 打分完成 | INFO | 岗位摘要、score、threshold、是否推荐（**不打印打分输入全文与画像全文**） |
| 推荐岗位 | INFO | group_id、message_id、岗位摘要、score（完整信息走控制台 print 业务展示） |
| 仅存档岗位 | INFO | group_id、message_id、岗位摘要、score、阈值（极简一行） |
| 岗位打分失败 | WARN | group_id、message_id、岗位摘要、错误信息（含错误码 PAR.LLM.001 / MAT.SCORE.001） |
| 打分响应格式非法，重试 | WARN | 第几次重试、错误信息 |
| 打分重试后仍失败 | WARN | 错误信息（含错误码） |
| 打分越界已截断 | WARN | 岗位摘要、raw 分数、截断后分数 |
| 打分跳过（画像未配置） | WARN | 岗位摘要（提示填写 user_resume / user_intention） |
| 公司风评检索完成 | INFO | company、检索资料长度（不打印检索原文全文） |
| 牛客浏览器检索成功/无有效内容 | INFO | company、资料长度 / company（同公司缓存复用） |
| 牛客浏览器检索失败 | INFO | company、错误原因（降级不影响打分） |
| 残缺字段补全完成 | INFO | company、job、补全的字段清单 |
| 残缺字段补全失败（保持残缺） | INFO | company、job、失败原因 |
| 残缺字段浏览器补全链路 | INFO | 渲染 URL、正文长度（HTTP 抓取失败降级浏览器时） |

> 补充说明：推荐岗位的**完整岗位信息**（公司/岗位/地点/学历/技术栈/投递方式/截止/理由）由 `main.py` 通过 `print` 输出到控制台（产品方案 4.6 查看入口），属于业务展示而非日志；日志侧保持摘要，符合敏感信息红线。

## 八、模块六日志点清单（当前实现）

| 日志点 | 级别 | 内容 |
| --- | --- | --- |
| 岗位归档 | INFO | 文件名、score、类型（推荐/仅存档） |
| 去重跳过（已归档，保留首次记录） | INFO | 岗位摘要、已存在文件名 |
| 打分失败岗位不入档 | WARN | 岗位摘要、错误信息（含错误码） |
| 岗位归档失败 / 异常 | WARN | 岗位摘要、错误信息（含错误码 STO.SAVE.001） |
| 历史/当日存档读取失败，跳过 | WARN | 文件名（损坏 JSON 单条跳过） |
| 日报已落盘 | INFO | 文件名、字节数 |
| 日报生成 | INFO | 文件名、推荐数、当日全量数 |
| 日报生成完成 | INFO | 文件名、推荐数、当日全量数（main 日志） |
| 日报生成失败 | ERROR | 错误信息（含错误码 STO.REPORT.001；不影响当日已归档数据） |
| 推荐标记全量重算完成 | INFO | 扫描数、更新数、失败数、阈值（v0.7.0） |
| 岗位自动去重完成 | INFO | 扫描数、重复组数、保留数、合并移动数、备份目录（v0.7.0） |
| 推荐标记重算跳过损坏文件 | WARN | 文件名（v0.7.0） |
| 推荐标记重算写回失败 | WARN | 文件名、错误原因（v0.7.0） |
| 手动录入岗位 | INFO | 公司/岗位摘要、score、是否推荐（v0.7.0，server.py） |
| 手动删除岗位 | INFO | 文件名、备份目录名（v0.7.0，server.py） |

> 补充说明：岗位 JSON 与日报正文均**不进入日志**，只记录文件名与统计数；岗位内容以控制台 `print` 业务展示（推荐岗位），符合敏感信息红线。

## 九、扩展约定

- 模块六日志命名空间为 `job_assistant.storage.repository` / `job_assistant.storage.report`（符合 `job_assistant.<包名>.<模块名>` 规范）
- 新增日志点先按本表登记，保持可检索
